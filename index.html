Core Projects

Project KASCVE

Automated Security Auditing Ecosystem & Perimeter Monitor

An automated penetration testing framework and passive reconnaissance ecosystem engineered for continuous attack surface monitoring. The pipeline starts with deep passive recon, aggregating subdomains from public threat intelligence sources to map out a target’s digital footprint entirely out-of-band. Once domain boundaries are verified via Cloudflare API validation, a high-velocity Go-based core switches to active penetration testing—programmatically whitelisting its own nodes to execute unhindered port probing and tech-stack fingerprinting without triggering WAF blocks. Real-time findings are ingested by a FastAPI backend, parsing banner data with regex heuristics to deliver instant security alerts and structured JSON remediation reports.
